# 🎯 Quiz Application (Flask Web Application)

## 📌 Project Overview
The Quiz Application is a web-based interactive system built using Python and Flask. It allows users to answer multiple-choice questions and receive scores based on their performance.

This project was developed as part of a Python internship task to understand application logic and user interaction.

---

## 🚀 Features
- ❓ Multiple-choice questions
- 🔄 One question at a time display
- 🎯 Automatic score calculation
- 📊 Final result with feedback
- 🔁 Play again functionality
- 🌐 Web-based user interface
- ⚡ Real-time interaction

---

## 🛠️ Technologies Used
- 🐍 Python
- ⚡ Flask (Web Framework)
- 🌐 HTML / CSS
